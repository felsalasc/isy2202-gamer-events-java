# Semana 5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Completar las funciones privadas del caso de semana 5 y preparar análisis reproducible.
**Architecture:** Servicios transaccionales compartidos por MVC y REST; DTO, autor autenticado y persistencia MySQL. Mantener JWT separado de las sesiones web con CSRF.
**Tech Stack:** Java 17, Spring Boot 4, MySQL 8.4, Thymeleaf, JUnit y MockMvc.
**Spec:** `docs/semana-5-diagnostico-y-primer-bloque.md`, aprobado para comenzar en la conversación.

## Global Constraints

- No publicar ni modificar la VM en este trabajo local.
- No borrar volúmenes ni datos existentes; añadir migraciones incrementales.
- Validar entradas y no exponer entidades JPA o credenciales.
- Reutilizar el checkout actual y la rama `codex/semana-5`; sin worktree nuevo.

## Review Focus

- Comentarios con HTML y texto blanco: escape de salida y rechazo del vacío.
- Puntuaciones repetidas y concurrentes: una por usuario y evento.
- Usuario distinto del propietario: no puede adjuntar medios ni compartir como propio.
- Archivos falsificados, grandes o rutas manipuladas: rechazados y nunca ejecutados.
- Bases de datos existentes: migración sin pérdida de usuarios y eventos.
